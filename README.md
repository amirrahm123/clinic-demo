# Praxisklinik Isarblick – design demo

A design demo by BuildLab: homepage for a fictional private clinic in Munich.
All names, people, reviews, contact details and images are fictional placeholders.

Next.js 16, TypeScript, Tailwind CSS v4. Bilingual: English at `/`, German at `/de`.

```bash
pnpm install
pnpm dev     # http://localhost:3000
pnpm build
```
